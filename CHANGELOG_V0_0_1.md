# KIYVO v0.0.1 — pre-launch

## Foundation

- Novo marco semântico v0.0.1, preservando rotas e dados legados por compatibilidade.
- Análise competitiva de 25 marketplaces, com decisões baseadas em segurança, entrega comprovável e UX honesta.
- Schema idempotente com 30+ estruturas para risco, device, escrow, disputas, key inventory, growth, agente e parceiro autorizado.

## Security and domain skills

- Contrato testável de skills com Zod.
- Skills reais de taxa, anti-fraude, risco e tokens de entrega.
- Coleta de fingerprint minimizada por hash e inspeção local de magic bytes para bloquear executáveis/scripts disfarçados.
- Reserva transacional de key única e ledger/escrow preparados no SQL.

## Compliance

- Importação de catálogo de parceiro é restrita a autorização documentada, URL externa e revisão humana; não há scraping agressivo nem mascaramento de origem.
